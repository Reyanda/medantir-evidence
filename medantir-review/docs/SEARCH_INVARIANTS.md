# Search execution invariants

A definitive systematic-review search may pass only when all of the following are true:

- the executed source is the source named in the strategy;
- database/platform syntax is explicit;
- every result page is traversed or the source reports zero results;
- reported hit count reconciles with the exported record count;
- raw access failures are surfaced rather than replaced with a different source;
- licensed sources require an authorized user session and database entitlement;
- truncation is a failure, not a successful result;
- source provenance survives normalization and deduplication;
- study-family linkage occurs after citation deduplication and does not collapse distinct reports from one study.
